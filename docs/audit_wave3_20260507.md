## A. EQ. 4′ MATHEMATICAL SOUNDNESS

The new contract equation (`docs/polarization_barrier_coupling.md` §3.1, L107–111):

```
ΔV_screen = ΔV_pin · tanh(ΔV_lin / ΔV_pin)         [V]               (Eq. 4′)
```

Implemented in `src/transport.py:115–147` (`_polarization_dipole_shift_ev`):

```python
delta_v_lin_v = -sigma_si * lambda_si / (constants.epsilon_0 * kappa_inf_metal)   # L144
delta_v_screen_v = delta_v_pin_v * float(np.tanh(delta_v_lin_v / delta_v_pin_v))  # L146
```

### A.1  Linear-limit recovery (ΔV_lin → 0)  — **PASS**

`tanh(x) = x − x³/3 + O(x⁵)`. For `|ΔV_lin| ≪ ΔV_pin`, `tanh(ΔV_lin/ΔV_pin) ≈ ΔV_lin/ΔV_pin`,
so `ΔV_screen ≈ ΔV_pin · (ΔV_lin/ΔV_pin) = ΔV_lin`. Eq. 4 (linear T–K) is recovered to
first order. The contract states this explicitly (L111 "tanh(x) ≈ x for |x| ≪ 1 recovers
Eq. 4 in the BTO/BFO regime").

The doc-side `wave2_5_after.py:31–34` re-implements the same form for the diagnostic
figure (independent code path), giving a redundant check.

### A.2  Saturation limit (ΔV_lin → ∞)  — **PASS**

`tanh(x) → ±1` as `x → ±∞`. Therefore `ΔV_screen → ±ΔV_pin`. The contract states this
(L111 "tanh(x) → ±1 for |x| ≫ 1 saturates at ±ΔV_pin"). Implementation calls `np.tanh`
directly (no manual approximation), so the saturation is exact in floating point.

### A.3  Sign behavior — **PASS**

`tanh` is an odd function and preserves sign of its argument. The implementation puts
the leading minus sign on `ΔV_lin` at L144 (`-sigma_si * lambda_si / ...`), then passes
that signed quantity through `tanh`. The output `delta_v_screen_v` therefore has the same
sign as `delta_v_lin_v`, which has the same sign as `-σ_pol`. Eq. 5/6's leading-minus
convention propagates unchanged. Cross-checked against the contract (L113 "the leading
minus and σ_pol sign convention propagate through tanh unchanged").

This is exactly the Wave-1 hard-FAIL fix preserved through Wave-2.5: for `P > 0`,
`σ_pol,top = −P` (Eq. 1) → `ΔV_lin > 0` → `ΔV_screen > 0` → `Δφ_top > 0` (raised);
`σ_pol,bot = +P` (Eq. 2) → `ΔV_lin < 0` → `ΔV_screen < 0` → `Δφ_bot < 0` (lowered).
Opposite-direction TER signature intact.

### A.4  Dimensional consistency — **PASS**

`ΔV_lin` has units [V]. `ΔV_pin` has units [V]. Argument of `tanh` is `[V]/[V] =
dimensionless`. Output is `[V] · tanh(dimensionless) = [V]`. The function returns a
scalar in volts; consumers in `_barriers_ev` (L186–197) add it to barrier values in eV
under the standard `Δφ_B [eV] = ΔV_screen [V]` convention (Eq. 5/6 numerical equivalence,
documented in `polarization_barrier_coupling.md` L78–79).

Unit conversions internal to the helper (L141–142) are also correct:
- `convert_back_polarization` returns µC/cm²; dividing by `1e2` gives C/m². Verified
  against `src/atomicunits.py:42–47` and the comment.
- `bohr_to_m` returns m. Verified against `src/atomicunits.py`.
- The product `(C/m²)·(m)/((F/m)·dimensionless) = (C·m)/(C/V) = V`. Clean.

## B. TUNG ENHANCEMENT FORMULA

Implementation in `src/transport.py:259–265`:

```python
sigma_top_ev = max(self.parameters.te_barrier_sigma_top_ev, 0.0)
sigma_bot_ev = max(self.parameters.te_barrier_sigma_bot_ev, 0.0)
kt_safe = max(k_t_ev, 1e-9)
top_inhom_log = min(0.5 * (sigma_top_ev / kt_safe) ** 2, 80.0)
bot_inhom_log = min(0.5 * (sigma_bot_ev / kt_safe) ** 2, 80.0)
top_injection = top_prefactor * np.exp(-top_barrier_ev / kt_safe + top_inhom_log)
bottom_injection = bottom_prefactor * np.exp(-bottom_barrier_ev / kt_safe + bot_inhom_log)
```

### B.1–B.3  From-scratch derivation — **PASS**

Start with `J(δφ) = A* T² exp(−(φ̄ + δφ)/kT)` for a single patch with barrier
deviation `δφ`. Average over a Gaussian distribution
`P(δφ) = (1/√(2π) σ_φ) · exp(−δφ²/(2σ_φ²))`:

```
⟨J⟩ = A* T² exp(−φ̄/kT) · (1/√(2π)/σ_φ) ∫_{−∞}^{∞} exp(−δφ/kT − δφ²/(2σ_φ²)) dδφ
```

Complete the square in the exponent:
```
−δφ/kT − δφ²/(2σ_φ²) = −(1/(2σ_φ²)) [δφ² + 2δφ σ_φ²/kT]
                     = −(1/(2σ_φ²)) [(δφ + σ_φ²/kT)² − σ_φ⁴/kT²]
                     = σ_φ²/(2 kT²) − (δφ + σ_φ²/kT)²/(2σ_φ²)
```

The Gaussian integral
`∫ exp(−(δφ + σ_φ²/kT)²/(2σ_φ²)) dδφ = √(2π) σ_φ`,
which cancels the prefactor `(1/√(2π)/σ_φ)`, leaving:

```
⟨J⟩ = A* T² exp(−φ̄/kT) · exp(σ_φ²/(2 (kT)²))
```

So the multiplicative enhancement is `exp(σ_φ²/(2 (kT)²))`. The implementation L264
puts this exponent inside the same `np.exp` as `-φ̄/kT`, i.e. multiplies the homogeneous
TE rate by `exp(σ²/(2(kT)²))`, which is identical to the analytic result. **PASS** on
formula and on placement (multiplicative on the homogeneous TE base, not on top of the
wrong base).

### B.4  Implementation placement — **PASS**

Quoting `src/transport.py:264`:
```python
top_injection = top_prefactor * np.exp(-top_barrier_ev / kt_safe + top_inhom_log)
```

`top_prefactor` is the standard A·m·T² Richardson product (L238–244). The Tung
factor `top_inhom_log = (1/2)(σ/kT)²` is added inside the same exponential as
`−φ̄/kT`, which is mathematically equivalent to multiplying by `exp((σ/kT)²/2)`.
No double application; no shadowing of the homogeneous base. **PASS.**

### B.5  Exponent cap is tight enough — **PASS**

At σ_φ = 0.30 eV (upper fit bound, see C.2 below) and T = 300 K:
- kT = 1.38e−23 J · 300 K / 1.602e−19 C = 0.025852 eV.
- σ_φ²/(2 (kT)²) = 0.09 / (2 · 6.683e−4) = 0.09 / 1.337e−3 ≈ 67.3.
- 67.3 < 80 (cap). Cap does not trigger inside the bounded fit domain.

Inside the fit's bound `te_barrier_sigma_*_ev ∈ [0.05, 0.30] eV`
(`src/fit_dciv_experiment.py:372–373`), the exponent is in [0.187, 67.3] — far below
80 throughout. The cap is a safety against unbounded callers, not a load-bearing
truncation.

### B.6  Citation check — **UNCERTAIN**

Citations in `src/transport.py:35–36` and `docs/polarization_barrier_coupling.md`-adjacent

### C.3  Identifiability of pinning vs Tung — **UNCERTAIN**

Pinning floor `ΔV_pin` controls the *cap* on the dipole shift (sets the maximum
asymmetry between top/bottom barriers when `|σ_pol|` is large). Tung σ_φ controls
the *prefactor multiplier* on TE current (raises both branches by the same factor
when σ_top = σ_bot, but allows differential boosting if σ_top ≠ σ_bot).

At a high level these affect different observables:
- Pinning → asymmetry in the *barrier height* (and therefore the *exponent* of TE).
- Tung → multiplicative *prefactor* on TE.

But in a fit they can trade off: a 1× change in σ_φ (e.g. 0.10 → 0.20) changes the
TE exponent by ~4 (factor of e⁴ ≈ 55), which a ~kT/2 = 12 mV shift in barrier height
also produces. So at a single observation point they are degenerate at the 0.01 eV
barrier-shift scale. Across a full I-V curve they should be separable in principle
(Tung is bias-independent multiplicative; pinning enters via P(V) which has hysteresis
shape), but I cannot verify without a covariance matrix.

The Wave-3 writeup itself notes that the Wave-3 default fit drops σ_bot to its lower
bound (0.050 eV) and σ_top to 0.089 eV — i.e. the fit prefers to leave Tung mostly
turned off and let other DOFs absorb the residual. This *is* informative: it tells
us the fit-level identifiability is asymmetric (Tung is bounded out by other channels).
But it does not prove formal identifiability.

**UNCERTAIN — pending covariance analysis.** Note as a follow-up; not blocking.
